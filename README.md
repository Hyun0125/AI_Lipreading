# AI를 활용한 청각장애인을 위한 발음 학습도우미

## 프로젝트 소개

본 프로젝트는 청각장애인의 발음 학습을 돕기 위한 AI 기반 발음 피드백 애플리케이션입니다.

청각장애인은 자신의 발음을 청각적으로 확인하기 어렵기 때문에 발음 오류를 스스로 인식하고 교정하는 데 어려움이 있습니다. 기존 발음 교정 시스템은 주로 음성 인식에 의존하거나 단순히 입모양을 보여주는 수준에 그치는 경우가 많아, 청각장애인에게 충분한 피드백을 제공하기 어렵다는 한계가 있습니다.

본 프로젝트는 사용자의 발음 영상과 음성을 함께 분석하여 음성 피드백, 입모양 피드백, 점수를 제공하는 발음 학습 도우미를 개발하는 것을 목표로 합니다.

## 개발 목적

본 프로젝트의 목적은 청각장애인이 시각 정보와 AI 분석 결과를 활용하여 자신의 발음을 이해하고 반복적으로 학습할 수 있도록 돕는 것입니다.

사용자가 자음, 모음, 단어, 문장을 선택하여 학습하고 직접 발음 영상을 촬영하면, AI가 음성과 입모양을 분석하여 발음 정확도와 개선 방향을 제공합니다.

이를 통해 사용자는 단순히 발음을 따라 하는 것이 아니라, 자신의 발음이 어떤 부분에서 부족한지 확인하고 반복 학습을 통해 발음을 개선할 수 있습니다.

## 연구 배경 및 필요성

청각장애인은 소리를 듣기 어렵거나 들을 수 없는 상태로 인해 자신의 발음을 청각적으로 확인하는 데 제한이 있습니다. 이로 인해 발음 오류를 스스로 인식하기 어렵고, 발음 교정 과정에서도 즉각적인 피드백을 받기 어렵습니다.

기존의 청각장애인을 위한 인공지능 기술은 주로 다음과 같은 분야에서 발전해 왔습니다.

| 구분 | 기술 요약 |
|---|---|
| 캡셔닝 | 음성 언어를 텍스트 언어로 변환 |
| 청각 보조 | 청각을 보조해 주는 스마트 디바이스 |
| 수화 통역 | 행동 언어를 텍스트 언어로 변환하거나 그 반대로 변환 |

이러한 기술들은 청각장애인의 의사소통을 돕는 데 기여하지만, 발화 능력 향상이나 발음 교정 측면에서는 여전히 한계가 있습니다.

특히 음성 인식 시스템은 청각장애인의 발화에서 더 높은 인식 오류율을 보일 수 있으며, 자음 발음 차이, 모음 길이 변화, 발화 속도 등이 인식 결과에 영향을 줄 수 있습니다.

따라서 청각장애인의 발음 학습을 위해서는 음성 정보뿐만 아니라 입모양과 같은 시각 정보를 함께 활용하는 발음 피드백 시스템이 필요합니다.

## 기존 시스템의 한계

기존 발음 교정 시스템은 다음과 같은 한계를 가집니다.

1. 대부분 음성 인식에 의존하여 청각장애인의 발음 특성을 충분히 반영하기 어렵습니다.
2. 시각 정보를 활용하더라도 단순히 입모양을 보여주는 수준에 그치는 경우가 많습니다.
3. 사용자가 왜 틀렸는지, 어떻게 개선해야 하는지에 대한 구체적인 피드백이 부족합니다.
4. 한국어 발음의 특성을 반영한 데이터와 분석 방식이 부족합니다.
5. 음성, 입모양, 발화 길이, 음량, 높낮이 등을 종합적으로 분석하는 구조가 부족합니다.

## 제안 시스템

본 프로젝트에서는 청각장애인의 효과적인 발음 학습을 위해 음성과 입모양을 통합적으로 분석하는 시청각 기반 발음 학습 도우미를 제안합니다.

사용자는 학습할 자음, 모음, 단어, 문장을 선택하고 발음 방법을 학습한 뒤, 직접 발음 영상을 촬영합니다. 이후 시스템은 영상과 음성을 분석하여 발음 정확도, 입모양 유사도, 음성 특징, 피드백 문구를 제공합니다.

본 시스템은 다음과 같은 특징을 가집니다.

- 음성 분석과 입모양 분석을 함께 수행
- 청각 정보에 의존하기 어려운 사용자를 위해 시각적 피드백 제공
- 발음별 기준 입모양 및 기준 발음 제공
- 발음 결과에 대한 점수와 피드백 제공
- 학습 기록 저장 및 복습 기능 제공
- 자음, 모음, 단어, 문장 단계별 학습 지원

## 시스템 구성

### 1. 프론트엔드 모듈

Flutter를 사용하여 모바일 애플리케이션 화면을 구현합니다.

주요 역할은 다음과 같습니다.

- 자음 / 모음 / 단어 / 문장 목록 표시
- 학습할 음소 선택
- 기준 영상 및 기준 음성 재생
- 카메라를 이용한 발음 영상 촬영
- 마이크를 이용한 음성 녹음
- 촬영 영상 미리보기
- 다시 촬영 기능 제공
- 영상 업로드
- 분석 결과 화면 표시
- 학습 기록 및 복습 화면 제공

### 프론트엔드 화면 구성

| 화면 | 주요 기능 |
|---|---|
| 학습 선택 화면 | 자음, 모음, 단어, 문장 선택 |
| 발음 연습 화면 | 기준 영상, 기준 음성, 촬영 기능 제공 |
| 결과 화면 | 총점, 음성 점수, 입모양 점수, 피드백 표시 |
| 기록 화면 | 최근 연습 기록, 최고 점수, 자주 틀린 항목 표시 |

### 2. 백엔드 모듈

FastAPI를 사용하여 클라이언트 요청을 처리하고 AI 분석 모듈과 연결합니다.

주요 역할은 다음과 같습니다.

- 영상 파일 업로드 처리
- 업로드된 파일 저장
- 사용자 정보 및 학습 항목 확인
- 전처리 모듈 호출
- 음성 분석 모듈 호출
- 입모양 분석 모듈 호출
- Whisper 음성 인식 모듈 호출
- 점수 계산
- 피드백 생성
- 분석 결과 반환
- 학습 기록 저장 및 조회

### 3. 전처리 모듈

사용자의 영상과 음성을 분석 가능한 형태로 변환합니다.

#### 영상 전처리

- 영상에서 프레임 추출
- FPS 통일
- 길이 제한
- 얼굴 검출
- 입술 영역 추출
- 이미지 크기 통일
- 프레임 수 통일
- 품질이 낮은 입력 제거

#### 음성 전처리

- 영상에서 음성 추출
- WAV 변환
- Mono 변환
- 16kHz 리샘플링
- 무음 구간 제거
- 발화 시작점 탐지
- 음량 정규화

### 4. 입모양 분석 모듈

MediaPipe FaceMesh와 OpenCV를 활용하여 사용자의 입술 움직임을 분석합니다.

주요 역할은 다음과 같습니다.

- 얼굴 검출
- 입 주변 랜드마크 추출
- 입술 좌표 저장
- 입술 ROI 추출
- 입 벌림 정도 분석
- 입술 원순성 분석
- 입모양 대칭성 분석
- 프레임별 입술 움직임 분석
- 기준 입모양과의 유사도 계산
- 입모양 점수 산출

### 5. 음성 분석 모듈

Librosa를 활용하여 사용자의 음성 특징을 분석합니다.

주요 분석 항목은 다음과 같습니다.

| 분석 항목 | 설명 |
|---|---|
| 발화 길이 | 사용자가 얼마나 길게 발음했는지 분석 |
| 음량 | 목소리가 너무 작지 않은지 분석 |
| 발음 속도 | 발화 시간과 음절 수를 기반으로 속도 분석 |
| Pitch | 발음의 높낮이 분석 |
| 안정성 | 발음이 일정하게 유지되는지 분석 |

### 6. 음성 인식 모듈

Whisper를 활용하여 사용자의 음성을 텍스트로 변환하고 목표 발음과 비교합니다.

주요 역할은 다음과 같습니다.

- 음성 파일 입력
- 음성 텍스트 변환
- 목표 발음과 인식 결과 비교
- 발음 일치 여부 판단
- 발음 유사도 계산

### 7. 점수 계산 모듈

음성 분석 결과와 입모양 분석 결과를 종합하여 최종 발음 점수를 계산합니다.

평가 요소는 다음과 같습니다.

| 평가 영역 | 세부 항목 | 가중치 |
|---|---|---|
| 정확도 | 음소 정확도 | 0.25 |
| 정확도 | 단어 발음 유사도 | 0.20 |
| 유창성 | 발음 속도 | 0.10 |
| 유창성 | 발음 길이 | 0.10 |
| 유창성 | 안정성 | 0.10 |
| 표현력 및 시각 정보 | 높낮이 | 0.10 |
| 표현력 및 시각 정보 | 음량 | 0.05 |
| 표현력 및 시각 정보 | 입모양 유사도 | 0.10 |

각 요소는 0점에서 100점 사이로 정규화한 뒤 가중치를 적용하여 최종 점수를 계산합니다.

### 점수 변수

| 변수 | 의미 |
|---|---|
| V | 음량 점수 |
| S | 발음 속도 점수 |
| D | 발음 길이 점수 |
| P | 높낮이 점수 |
| A | 음소 정확도 점수 |
| W | 단어 발음 유사도 |
| L | 입모양 유사도 |
| T | 발음 안정성 |

최종 점수는 0점에서 100점 사이로 표현되며, 사용자가 자신의 발음 상태를 직관적으로 확인할 수 있도록 합니다.

### 8. 피드백 생성 모듈

분석 결과를 바탕으로 사용자가 이해하기 쉬운 피드백 문장을 생성합니다.

| 분석 기준 | 상태 | 피드백 예시 |
|---|---|---|
| 입 벌림 정도 | 낮음 | 입을 더 크게 벌리세요. |
| 입술 원순성 | 낮음 | 입술을 앞으로 더 모아주세요. |
| 입모양 대칭성 | 낮음 | 입 모양의 좌우 균형을 맞춰보세요. |
| 발화 길이 | 부족 | 조금 더 길게 발음해보세요. |
| 음량 | 부족 | 좀 더 크게 발음해보세요. |
| 발음 유사도 | 낮음 | 목표 발음과 다른 소리로 인식되었습니다. |

### 9. 저장 및 기록 모듈

사용자의 학습 결과를 저장하여 복습 기능에 활용합니다.

저장되는 정보는 다음과 같습니다.

```text
- 사용자 정보
- 학습 종류: 자음 / 모음 / 단어 / 문장
- 학습 항목
- 영상 파일 경로
- 학습 날짜
- 음성 피드백
- 입모양 피드백
- 음성 점수
- 입모양 점수
- 총점
- 최고 점수
- 평균 점수
- 시도 횟수
```

## 역할 분담

| 담당자 | 담당 파트 | 주요 업무 |
|---|---|---|
| 이현경 | AI 모듈 | 음성 분석, 입모양 분석, 발음 점수 계산, AI 피드백 생성 |
| 이다은 | Frontend / Backend / Database | Flutter 앱 구현, FastAPI 서버 구축, 영상 업로드 API 구현, 학습 기록 저장 및 조회 기능 구현 |

## 세부 역할

### 이현경 - AI 모듈

- Whisper를 활용한 음성 인식
- 목표 발음과 인식 결과 비교
- Librosa 기반 음성 특징 분석
- MediaPipe FaceMesh 기반 입술 랜드마크 추출
- OpenCV 기반 입술 영역 처리
- 입모양 좌표 기반 영상 분석
- 음성 점수 및 입모양 점수 계산
- 분석 결과를 바탕으로 피드백 문장 생성
- Backend와 연동 가능한 AI 분석 함수 구조화

### 이다은 - Frontend / Backend / Database

- Flutter 기반 모바일 앱 화면 구현
- 자음, 모음, 단어, 문장 학습 화면 구성
- 학습모드 및 복습모드 화면 전환 구현
- 카메라 촬영 및 영상 미리보기 기능 구현
- FastAPI 기반 서버 구현
- 사용자 촬영 영상 업로드 처리
- AI 분석 모듈 호출 및 결과 반환
- MySQL 기반 학습 기록 저장
- 복습 데이터 조회 기능 구현

## 실행 방법

### Backend 실행

```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend 실행

```bash
cd frontend
flutter pub get
flutter run
```

## 기대 효과

본 프로젝트를 통해 청각장애인은 자신의 발음을 단순히 듣는 방식이 아니라 시각적 정보와 AI 분석 결과를 통해 확인할 수 있습니다.

또한 음성 피드백과 입모양 피드백을 함께 제공함으로써 사용자는 자신이 어떤 부분에서 발음 오류를 보였는지 구체적으로 이해할 수 있습니다.

이를 통해 반복 학습 과정에서 발음 정확도를 점진적으로 개선하고, 한국어 발음 학습에 필요한 개인 맞춤형 피드백을 제공할 수 있을 것으로 기대됩니다.
